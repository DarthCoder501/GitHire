# Avatar Model

Place your GLB avatar model file here as `avatar.glb`.

## Recommended Sources

1. **ReadyPlayerMe**: https://readyplayer.me/ - Free avatar creation with GLB export
2. **Sketchfab**: https://sketchfab.com/ - Search for free GLB models with morph targets

## Requirements

- Format: GLB (binary glTF)
- Should include morph targets for mouth animation
- Common morph target names: "mouthOpen", "viseme_aa", "viseme_O", etc.
- Recommended size: < 5MB for fast loading

## Testing Without a Model

If you don't have an avatar model yet, the application will still run but the avatar won't be visible. You can test the audio pipeline and UI independently.
